# Executable lesson scope

.NET SDK 11.0.100 runs official MCP C# SDK 2.4.0 with protocol 2025-11-25 pinned explicitly. SDK and protocol versions are separate. All data, users, JWT signing keys and side effects are owned teaching fixtures. HTTP endpoints bind only to loopback and validate bearer tokens where demonstrated. This is not a deployed OAuth authorization server.

The required official authorization filters remain enabled. A deliberately overbroad write policy plus a bypassed business check supplies the controlled failure. Correct policy enforces primitive visibility and invocation attributes, with an independent business permission check and a verified positive operator mutation. A new signed reader token simulates a role change after operator discovery; this is not a claim that an already issued JWT is instantly revoked by changing a database role. Actual stateless HTTP calls re-evaluate the current token. No caller token is forwarded to a downstream service.
