# Executable lesson scope

.NET SDK 11.0.100 runs official MCP C# SDK 2.4.0 with protocol 2025-11-25 pinned explicitly. SDK and protocol versions are separate. All data, users, JWT signing keys and side effects are owned teaching fixtures. HTTP endpoints bind only to loopback and validate bearer tokens where demonstrated. This is not a deployed OAuth authorization server.

Actual SDK prompts/list and prompts/get return parameterized text plus an EmbeddedResourceBlock. The host composes those into fixed system instructions and untrusted user data. No model inference or tool mutation is claimed in this protocol-composition lesson. Labels and role separation alone do not guarantee prompt-injection resistance; authorization must remain independently enforced by the host and services.
