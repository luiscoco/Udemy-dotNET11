# Executable model lesson scope

.NET SDK 11.0.100 with separately pinned packages and model assets. All business fixtures are synthetic. Build, controlled failure and repair execute actual code.

Actual SDCA logistic regression on synthetic two-dimensional data, held-out evaluation, precision/recall and full confusion counts. The positive label is explicit. The controlled threshold above probability one rejects every positive and fails recall; model training still occurs. Fixture thresholds demonstrate regression detection, not production accuracy or a universal operating threshold.
