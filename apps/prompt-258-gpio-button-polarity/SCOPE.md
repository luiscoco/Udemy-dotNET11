# Executable extensibility lesson scope

.NET SDK 11.0.100. Library, compiler and engine versions are independent. All effects use owned synthetic fixtures.

Actual System.Device.Gpio and Iot.Device.Bindings packages use an explicitly authored software GpioDriver on this Windows desktop. A read-only controller probe is retained. No physical board, voltage, wiring, sensor accuracy or physical GPIO writes are claimed. Active-low input transitions are deterministic teaching fixtures. For a real board use a supported driver, correct wiring and electrical limits.
