.NET SDK 11.0.100. Library, compiler and engine versions are independent. All effects use owned synthetic fixtures.

Actual Windows MAUI 11 application and native WinUI RenderTargetBitmap capture. Offline edits persist in real SQLite and survive conflicts. Real HTTP synchronization uses an ephemeral signed JWT, explicit conflict resolution and operation-ID replay protection. The problem omits the credential and retains the offline edit after a real 401. The verification window is moved off-screen, and only its rendered owned controls are captured. Windows only was executed; mobile platforms and production OAuth sign-in are not claimed. Local token provisioning is an isolated test fixture, not a recommended login flow.
