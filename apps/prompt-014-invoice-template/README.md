# Prompt 14 — reusable invoice template

Requires .NET SDK 11.0.100 or a compatible patch and Node.js. Run node verify.cjs for the complete verified exercise, or node lab-server.cjs and open http://127.0.0.1:4177 for the interactive lab. Read EXERCISE.txt. Generated outputs are confined to this lesson. Verification records real process output in artifacts/verification.json and restores its known source mutations. Run one experiment at a time on an unmodified exercise copy.

The template engine --debug:custom-hive flag is used only to isolate this course experiment from your usual installed templates. The normal public workflow is dotnet new install followed by dotnet new SHORTNAME. The exercise regenerates only its own artifacts/OrdersApp folder using --force; preserve any edits you wish to retain before rerunning.
