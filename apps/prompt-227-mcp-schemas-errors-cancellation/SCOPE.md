# Executable lesson scope

.NET SDK 11.0.100 runs official MCP C# SDK 2.4.0 with protocol 2025-11-25 pinned explicitly. SDK and protocol versions are separate. All data, users, JWT signing keys and side effects are owned teaching fixtures. HTTP endpoints bind only to loopback and validate bearer tokens where demonstrated. This is not a deployed OAuth authorization server.

Real SDK discovery and calls verify argument types, explicit C# business validation and controlled tool errors. Cancellation is requested only after an actual server-start marker; the test separately requires the server cancellation marker and no completion marker. A wrong-type argument, a domain violation and cancellation are distinct outcomes. The delay and disconnect tools are owned diagnostic fixtures, not production business operations.
