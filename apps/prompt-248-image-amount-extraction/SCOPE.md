# Executable model lesson scope

.NET SDK 11.0.100 with separately pinned packages and model assets. All business fixtures are synthetic. Build, controlled failure and repair execute actual code.

Actual MNIST ONNX image inference on five known 28x28 handwritten digit cells, decoded from PNG using SkiaSharp 4.157.0. This is narrow fixed-template amount recognition, not general invoice OCR, a multimodal language model or arbitrary-document understanding. EUR is trusted template metadata, not inferred text. Two decimal places are a documented template rule. Softmax confidence is uncalibrated; semantic and layout checks remain independent. Held-out digit provenance and expected amount are supplied for verification.
