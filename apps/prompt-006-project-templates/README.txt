These .NET 11 examples were prepared for teaching and were not executed on .NET 11 on the production machine. Install and select a suitable .NET 11 SDK before running them.

Run commands from this practice directory unless the setup script creates a Workspace directory.

Run setup.ps1 once in a fresh exercise folder. It generates net11.0 templates using your installed SDK, retaining template package versions. Run Workspace/Api, Workspace/Web and Workspace/Jobs separately with dotnet run --project. The Blazor excerpt is a reading guide, not a complete replacement startup file.
