# Executable model lesson scope

.NET SDK 11.0.100 with separately pinned packages and model assets. All business fixtures are synthetic. Build, controlled failure and repair execute actual code.

Actual SSA forecasting with 70 training days, seven validation days and a later untouched seven-day test window. Configuration is fixed before the test. A separate sequential IID spike detector processes an explicitly synthetic spike. An anomaly alert is not a forecast; confidence is an algorithm parameter, not guaranteed future accuracy. This bounded window demonstration does not claim broad backtesting or real demand prediction.
