# Executable lesson scope

.NET SDK 11.0.100 runs official MCP C# SDK 2.4.0 with protocol 2025-11-25 pinned explicitly. SDK and protocol versions are separate. All data, users, JWT signing keys and side effects are owned teaching fixtures. HTTP endpoints bind only to loopback and validate bearer tokens where demonstrated. This is not a deployed OAuth authorization server.

Actual HTTP fault injection checks malformed JSON and an unsupported resources/list method. A real stdio child exits itself after validating its unique launch nonce; the client observes disconnect and reconnects to a new process. Cancellation waits for explicit server markers. Client capability checks are distinct from the raw server rejection. No unrelated process is terminated.
