# Local inference scope

The recording uses Ollama 0.40.16 and Qwen2.5 0.5B, with pinned .NET packages in App.csproj and packages.lock.json. Requests execute actual model inference; model wording is not asserted. Deterministic safety assertions inspect application boundaries and controlled fixtures explicitly. Tool authorization and user isolation are enforced by application code, independently of model compliance. Model output is untrusted.

This endpoint performs actual retrieval and structured chat inference. The model selects a retrieved evidence index; the server returns an extractive quotation and source citation. PostgreSQL keyword evidence gates abstention, so nearest-neighbor existence alone is insufficient. The small model is not entrusted to invent citations or authorize documents. The bad fallback actually requests unsupported generation and fails the HTTP contract. Browser automation verifies the real endpoint UI. Production authentication, semantic answer completeness and a generative paraphrase evaluator are outside this fixture.
