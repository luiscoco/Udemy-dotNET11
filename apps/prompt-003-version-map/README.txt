These .NET 11 examples were prepared for teaching and were not executed on .NET 11 on the production machine. Install and select a suitable .NET 11 SDK before running them.

Run commands from this practice directory unless the setup script creates a Workspace directory.

Inspect global.json and App/App.csproj. Run dotnet --version, dotnet --list-runtimes, dotnet workload --version, and dotnet workload list. The example latestPatch policy requires an eligible 11.0.1xx SDK. Install it or deliberately revise the policy if your installed SDK differs.
